# Navrang Skill

This repository contains:
- `backend/`: Express.js API server with Knex, MySQL, JWT auth, notifications, receipts, stock, sales, and user management.
- `apps/mobile/`: Expo React Native app using `expo-router`, React Query, Axios, and shared package `@navrang/core`.
- `apps/smoke-app/`: smoke app used to validate mobile workflows.
- `packages/core/`: shared code used by the mobile apps.

Skill guidance:
- When responding to code requests, reference actual file paths and existing patterns.
- When editing, keep changes minimal and aligned with current folder structure.
- When reviewing problems, identify whether they are backend, mobile, or shared package issues.
- When possible, include file names, code snippets, and test instructions.
- Do not assume the presence of files or features not shown in the repository.
