# Navrang Workspace Instructions

This repository is a JavaScript/TypeScript monorepo centered on a Node.js backend plus Expo mobile applications.

Root folders:
- `backend`: Express.js + Knex + MySQL API server with authentication, notification queue, receipt, stock, sale, and user management features.
- `apps/mobile`: Expo React Native application using `expo-router`, React Query, Axios, shared package `@navrang/core`, and Expo Notifications.
- `apps/smoke-app`: companion Expo smoke test app with a minimal mobile surface area.
- `packages/core`: shared internal package used by mobile apps.

When answering user requests:
- Prefer actual files and real paths from this repo.
- Keep edits minimal and aligned with existing naming, style, and architecture.
- Use the existing stack: Express, Knex, Jest, Expo, React Native, TypeScript, React Query.
- Avoid speculative or unrelated code changes.
- If the request is ambiguous, ask a clarifying question before editing.
- Include exact file names, snippets, and testing guidance when proposing changes.

For code changes:
- Reference controllers, routes, models, middleware, and tests in the backend.
- Reference Expo router pages, components, hooks, and shared package usage in mobile apps.
- Respect existing conventions for camelCase, async/await, and Express error handling.
- Prefer small, targeted patches rather than large rewrites unless explicitly requested.
